# React Class-Based Component — GoMyCode Checkpoint

A simple React app built as part of the GoMyCode MERN + AI bootcamp, demonstrating class-based components and React lifecycle methods.

## What it does

- Displays a **person profile card** (name, bio, profession, photo)
- A button **toggles** the profile card visibility
- A **live timer** shows how many seconds have passed since the component mounted

## Concepts covered

- Class-based components (`extends Component`)
- State initialization in the `constructor`
- `setState` with functional form (`prev => ...`)
- Lifecycle methods: `componentDidMount` and `componentWillUnmount`
- `setInterval` and `clearInterval` for side effects
- Conditional rendering with `&&`
- Arrow function class methods for `this` binding

## Tech stack

- React (Vite)
- CSS (no external UI library)

## Getting started

```bash
npm install
npm run dev
```
